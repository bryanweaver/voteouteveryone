# VoteOut - Ballot Guide Card Design

## Design Specifications

### Card Format Options

We'll offer two physical formats:

1. **Wallet Card:** 3.5" x 2" (standard business card size)
2. **Postcard:** 4" x 6" (USPS standard postcard)

**Recommended Primary Format:** 4" x 6" postcard
- More space for multiple races
- USPS First Class Mail compatible
- Easy to read without folding
- Printable on standard paper (2 per sheet)

## Design Principles

### Typography
- **Font Family:** Inter, Helvetica, or Arial (clean, readable)
- **Sizes:**
  - Headlines: 16-18pt bold
  - Candidate names: 12-14pt
  - Body text: 10-11pt
  - Footer: 8pt
- **Weight:** Bold for office names and non-incumbents, Regular for incumbents
- **Contrast:** Black text on white background (high contrast for copying)

### Color Scheme (Print-Friendly)

**Primary Palette:**
- **Background:** White (#FFFFFF)
- **Text:** Black (#000000)
- **Non-incumbent indicator:** Green (#22C55E) or Black with ✓
- **Incumbent indicator:** Red (#EF4444) or Gray (#6B7280) with ✗
- **Section dividers:** Dark gray (#374151)

**Note:** For B&W printing, use symbols (✓ ✗) not just color.

### Visual Hierarchy

1. **Office name** - Bold, all caps, dark background bar
2. **Non-incumbent candidates** - Green checkmark, bold
3. **Incumbent candidates** - Gray text, crossed out or grayed
4. **Party affiliation** - Parentheses, abbreviated (D/R/I/NP)
5. **Years in office** - Small, gray, after incumbent name

### Spacing & Layout

- **Margins:** 0.25" all sides (safe print area)
- **Line height:** 1.3-1.5 for readability
- **Section spacing:** 0.15" between races
- **Candidate spacing:** 0.08" between candidates

### PDF Generation API Route

```typescript
// app/api/pdf/route.ts

import { NextRequest, NextResponse } from 'next/server';
import { renderToStream } from '@react-pdf/renderer';
import { BallotPDFDocument } from '@/components/pdf/BallotPDFDocument';
import { createClient } from '@/lib/database/supabase';
import QRCode from 'qrcode';

export async function POST(request: NextRequest) {
  try {
    const { ballotId } = await request.json();

    if (!ballotId) {
      return NextResponse.json({ error: 'Ballot ID required' }, { status: 400 });
    }

    // Fetch ballot from cache
    const supabase = createClient();
    const { data: cached, error } = await supabase
      .from('ballot_cache')
      .select('ballot_data')
      .eq('id', ballotId)
      .single();

    if (error || !cached) {
      return NextResponse.json({ error: 'Ballot not found' }, { status: 404 });
    }

    const ballot = cached.ballot_data;

    // Generate QR code (links to full ballot on website)
    const ballotUrl = `${process.env.NEXT_PUBLIC_APP_URL}/ballot/results/${ballotId}`;
    const qrCodeDataUrl = await QRCode.toDataURL(ballotUrl, {
      width: 200,
      margin: 1,
    });

    // Render PDF
    const pdfStream = await renderToStream(
      <BallotPDFDocument ballot={ballot} qrCodeDataUrl={qrCodeDataUrl} />
    );

    // Log usage
    await supabase.from('usage_stats').insert({
      event_type: 'pdf_download',
      state: ballot.address.state,
      zip_code: ballot.address.zip,
    });

    // Return PDF as download
    return new NextResponse(pdfStream as any, {
      headers: {
        'Content-Type': 'application/pdf',
        'Content-Disposition': `attachment; filename="ballot-guide-${ballot.electionDate}.pdf"`,
      },
    });
  } catch (error) {
    console.error('Error generating PDF:', error);
    return NextResponse.json(
      { error: 'Failed to generate PDF' },
      { status: 500 }
    );
  }
}
```

## Accessibility Considerations

### For Print

1. **High Contrast:** Black on white ensures readability for low vision
2. **Large Text:** Minimum 10pt, ideally 11-12pt for body text
3. **Clear Symbols:** ✓ and ✗ are universally recognized
4. **Simple Layout:** No complex grids or overlapping elements

### For Screen Readers (Digital Version)

```tsx
<div role="article" aria-label={`Ballot guide for ${electionName}`}>
  <section aria-labelledby="contest-1">
    <h3 id="contest-1">U.S. Senate</h3>
```
